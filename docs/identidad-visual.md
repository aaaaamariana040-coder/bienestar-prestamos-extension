# Identidad Visual Institucional
Aplicación de Préstamos de Bienestar Social — Politécnico Colombiano Jaime Isaza Cadavid

> Fuente: *Manual de Identidad Gráfica Institucional 2025*, Politécnico Colombiano Jaime Isaza Cadavid. Este documento extrae únicamente lo relevante para la aplicación web del proyecto (colores y tipografía); no sustituye el manual oficial para otros usos (impresos, material promocional, redes sociales, etc.).

| Color | HEX | RGB | Uso |
|---|---|---|---|
| Turquesa claro | `#00C3BE` | 0, 195, 190 | General |
| Turquesa oscuro | `#00A49A` | 0, 164, 154 | General |

### 1.4 Uso sugerido en la aplicación
Para la interfaz web (botones, enlaces, estados, encabezados), el manual no define un color único de "marca digital", así que se propone:
- **Color primario:** `#00AB44` (verde institucional) — es el tono central de la franja verde del escudo y el más usado como fondo de piezas oficiales.
- **Color de acento / llamadas a la acción:** `#FFD400` (amarillo institucional).
- **Evitar:** el morado `#79067F` (reservado exclusivamente para campañas de género) y cualquier color fuera de esta paleta.

## 2. Tipografía

### 2.1 Principal — familia AmsiPro
Tipografía institucional para todo texto de marca: títulos, cuerpo de texto, UI.

Variantes disponibles: `AmsiPro-Light`, `AmsiPro-Regular`, `AmsiPro-SemiBold`, `AmsiPro-Bold`, `AmsiPro-Black`, `AmsiPro-Ultra`.

> **Restricción explícita del manual:** no se permite el uso de la variante **AmsiPro Condensed**.

### 2.2 Uso especial — Attractype Reborn
Tipografía manuscrita/decorativa, de uso puntual (títulos llamativos en piezas de comunicación/redes). **No debe usarse en la interfaz del sistema** — es para piezas gráficas de divulgación, no para una aplicación institucional de gestión.

### 2.3 Nota sobre licencias
AmsiPro no es una fuente de Google Fonts ni de uso libre; si se usa en la web, se necesitaría la licencia/archivos de fuente de la institución (consultar con la Oficina Asesora de Comunicaciones). Como alternativa de respaldo sin licencia, se puede usar una tipografía similar de paso geométrico/humanista (ej. "Inter" o "Source Sans") hasta contar con los archivos oficiales.

## 3. Logosímbolo

- **Dos aplicaciones:** horizontal (escudo + texto al lado) y vertical (escudo arriba, texto debajo). En la aplicación web se recomienda la horizontal para el encabezado/navbar y la vertical para pantallas de login o espacios más angostos.
- **Área de reserva:** debe respetarse un espacio libre alrededor del logosímbolo equivalente al ancho de la letra "P" del wordmark, sin que otros elementos lo invadan.
- **Tamaño mínimo:** 1,5 cm de alto en distribución vertical, 1 cm en horizontal (el escudo solo puede ir hasta 1 cm de alto). Para la web, esto se traduce en nunca mostrar el logo por debajo de un tamaño que lo haga ilegible — se recomienda no bajar de ~32px de alto en pantalla.
- **Colores permitidos:** versión a color original, o en una sola tinta (blanco o negro) según el fondo, para garantizar contraste.
- **Usos NO permitidos:** cambiar tamaños relativos entre elementos, cambiar los colores del escudo, usar fondos que dificulten la lectura, cambiar el color de la tipografía, deformar el logosímbolo, o reordenar sus elementos.
- **Dependencias:** las unidades académicas/administrativas (como "Bienestar Social") no tienen logo propio — se identifican solo con texto al lado izquierdo del logosímbolo institucional, en AmsiPro-Bold.
