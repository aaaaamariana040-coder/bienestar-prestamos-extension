**requisitos funcionales**

| ID | Funcionalidad general | Descripción del requisito |
| ----- | ----- | ----- |
| **RF-001** | Gestión de usuarios y acceso | El sistema debe permitir autenticar usuarios y administrar sus cuentas, roles y permisos de acceso a las funcionalidades de Bienestar Social. |
| **RF-002** | Gestión de empleados | El sistema debe permitir registrar, consultar y actualizar la información de los empleados que soliciten o tengan préstamos administrados por Bienestar Social, incluyendo la consulta de su historial crediticio. |
| **RF-003** | Gestión de modalidades y parámetros | El sistema debe permitir administrar las modalidades de crédito y configurar sus condiciones, incluyendo monto máximo, plazo, tasa de interés y demás parámetros establecidos por la institución y la normativa aplicable. |
| **RF-004** | Gestión y control presupuestal | El sistema debe permitir registrar y administrar el presupuesto destinado a cada modalidad de crédito, mostrando los valores asignados, comprometidos y disponibles, así como su historial de modificaciones. |
| **RF-005** | Gestión de solicitudes | El sistema debe permitir registrar, consultar y validar solicitudes de préstamo, verificando las condiciones del solicitante y la disponibilidad presupuestal antes de su aprobación. |
| **RF-006** | Gestión de préstamos y desembolsos | El sistema debe permitir gestionar los préstamos aprobados y registrar sus desembolsos, incluyendo los desembolsos por tramos y las condiciones requeridas para desembolsos posteriores cuando corresponda. |
| **RF-007** | Gestión de amortización y pagos | El sistema debe generar y consultar la tabla de amortización de los préstamos, registrar y aplicar pagos, abonos y cancelaciones, y permitir consultar el estado de cuenta y las cuotas pendientes. |
| **RF-008** | Gestión de situaciones especiales del préstamo | El sistema debe permitir gestionar la reliquidación de préstamos, los abonos de cesantías y las situaciones derivadas del retiro del empleado, incluyendo la liquidación del saldo cuando corresponda. |
| **RF-009** | Reportes e indicadores | El sistema debe permitir consultar indicadores y generar reportes de préstamos, pagos, cartera y presupuesto, incluyendo información agrupada por modalidad y períodos determinados. |
| **RF-010** | Auditoría y trazabilidad | El sistema debe registrar y permitir consultar las operaciones relevantes realizadas por los usuarios, así como la trazabilidad de los préstamos desde su solicitud hasta su finalización. |
